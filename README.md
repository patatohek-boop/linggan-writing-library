# 灵感写作资料库

收录 77 项写作任务的聊天、逐任务 Word 与 Markdown，以及聊天内的原始附件。

[打开在线资料库](https://patatohek-boop.github.io/linggan-writing-library/#task-001)

网页提供项目筛选、主题分类、全文搜索、文档正文预览、文件下载、书签、阅读字号和夜间模式。显示设置与书签仅保存在访问者自己的浏览器中。

## 文件

- `index.html`：网页入口，与 `archive-*.js` 数据文件一起发布。
- `inspiration-archive.zip`：完整资料包，包含逐任务文档、聊天内原始文件和离线网页。

离线使用：将整个 ZIP 解压到同一文件夹，打开其中的 `index.html`。聊天与附件文字无需联网即可搜索阅读，文档下载使用解压后的相对路径。

资料按原聊天归档。未有后续答复的提问会保留在记录中。
