# 灵感写作资料库

收录 62 项写作任务的聊天、逐任务 Word 与 Markdown，以及聊天内的原始附件。

网页提供分类、全文搜索、文档正文预览、文件下载、书签、阅读字号和夜间模式。显示设置与书签仅保存在访问者自己的浏览器中。

## 文件

- `index.html`：完整的独立网页，包含所有聊天、附件文字与逐项文件下载。
- `inspiration-archive.zip`：完整资料包，包含逐任务文档、聊天内原始文件和离线网页。

资料按原聊天归档。未有后续答复的提问会保留在记录中。

## 归档说明

- 写作建议2：原聊天首轮请求后未显示助手答复正文；续问“继续”后的回复已完整收录。
