1. 主角的格调：让同一个动作，随着经历改变意义

原文

主角做些有格调的事情（登高远眺，说些有趣的台词，参考曹操，而且可以前后呼应）ideas

注释

这里最有价值的，其实是“前后呼应”。登高、饮酒、听曲、修器物，都可以成为人物的标志动作；但如果每次出现都只是配上一句豪言，就容易变成固定的耍帅程序。

可以保留动作，让他注意到的东西发生变化。

延伸示例

第一次登城，他看远处的旗帜，说：“地方够大。”

第二次登城，他不再看旗帜，而是开始数城外的炊烟，问这些人冬天在哪里过。

第三次，城外刚经历大火。他仍登上同一个地方，却只问：

“人都接进来了没有？”

三次都可以写得有气势，但人物关注的对象已经不同。

另一种不那么沉重的写法，是让主角真正喜欢一件事情：修旧乐器、辨别纸张、给朋友做饭。没有观众时，他仍愿意认真做，这种偏好比反复宣称“他很有品位”更值得写。

不必把每个爱好都解释成创伤，也不必让所有格调最终都归结为责任。有人就是喜欢山水、好酒和好天气，这也可以成立。

2. 配角的共鸣：给他一个小愿望，再让愿望长成立场

原文

配角可以给一些读者在现实中容易产生共鸣的情感体验（主角也可以适当提供）ideas

注释

建议把“共鸣”从抽象情绪改成一个具体愿望。

不要只写“他怀才不遇”“他很孤独”，而可以写成：他希望有人记住自己的本名；他想回家，但不愿让家人看到自己混得不好；他已经帮过所有人，却不好意思开口请别人帮一次忙。

延伸示例

一个书记员参与了一件大事。论功时，他没有求升迁，只要求正式记录里写上自己的名字——大家一直把他叫成前任的名字。

主角替他纠正了。

后来，主角为了维持士气，准备美化一次失败。最先站出来要求如实记录的，也是这个书记员。

这样，“希望被看见”的小愿望，就发展成了“记录不能随权力更改”的立场。他不再只是让读者感动一下的配角，也不是被主角帮助后便失去独立判断的人。

你以后给重要配角补笔记时，可以只补三句话：

他自己想要什么？
他已经为此做了什么？
他会因为什么事情反对主角？

3. 传闻与称号：先带来好处，再产生故事压力

原文

传闻与称号用来衬托主角ideas

注释

这条可以从“别人夸主角”进一步发展为：

称号有来历，传播会变形，而变形后的名声又会影响主角。

同一个称号，在不同人嘴里可以完全不同：普通人用来表达感谢，官方用来宣传，敌人用来预测他的行动，朋友则可能故意不用这个称号。

延伸示例

主角因一次护送获得“不弃一人”的称号。

这个称号先带来实实在在的收益：有人愿意跟随他，陌生人愿意提供帮助，敌人也开始忌惮他。

随后，对手发现他会被这句评价约束，故意制造两处同时需要救援的危机。

下一段情节就不必只是“主角突然变得更强”。他可以识破对方的预判、重新组织合作、利用信息差争取时间，也可能必须承认自己无法独自兑现所有承诺。

**先让名声帮助他，再让名声考验他，最后让他重新定义这个称号。**这样，衬托人物的材料就能进入长线剧情。

4. 愿望与全球直播：把一个好愿望写出持续后果

原文

设定成来源于现代的一个愿望呢？全球直播？ideas

注释

这句话里其实有两个方向：“愿望成为世界的起因”，以及“全球直播成为世界的运行机制”。两者可以分开写，也可以结合。

最需要补的不是许愿时的奇观，而是：愿望如何被解释，哪些人获益，哪些人不愿接受，以及它怎样持续影响日常生活。

延伸示例

有人许愿：

“希望每一个人的努力，都能被看见。”

于是，世界出现了一套无处不在的观看机制。

开篇先让愿望真正生效：被冒领的功劳得以澄清，默默救人的人得到帮助，普通人的能力终于有机会被认可。这样，读者才能理解它为什么受到欢迎。

随后，问题出现：有人不愿公开自己的经历，却被怀疑心虚；有人只做适合展示的好事；有人发现，自己最珍视的关系不适合被观众评价。

主角面对的一次重要选择可以是：公开一段影像就能证明自己的清白，但影像同时会暴露另一个人不愿公开的经历。

他不能只靠一句漂亮台词解决问题，而需要找到新的证明方式。世界设定因此与调查、关系、名声和成长连接起来。

5. 被遗忘的游戏：最有潜力的是“重逢之后”

原文

赛博重力女鬼（来源于deepseek被遗忘的小游戏——一个制作的ds为主角的游戏，作者自己忘了，但是设定的好感度是随着日期增加的，也就是虽然以往，但在角落里仍然默默涨好感度等待作者回来）ideas

注释

这条已经非常接近完整的故事种子。

在我的理解中，它的吸引力不只是“角色很痴情”，而是：创作者随手写下的一条规则，可能成为另一个主体无法自行选择的生活。

但目前还需要区分：原案例实际发生了什么，以及你准备把它虚构成什么。本次未能核准小游戏的原作者、原帖及具体实现方式，因此文档中保留了“来源待核”的标记，没有把它当成已经证实的事件。

延伸方向

方向可以怎样发展
温柔而遗憾她记得约定，也已经拥有自己的朋友和生活。创作者回来了，却发现自己不再是她全部的世界。
诡异而压迫假定角色在作品中拥有真实意识：创作者离开的几个月，对她而言经历了漫长时间；重逢时，她仍按最初设定说着同一句欢迎词。恐怖来自这句话背后被压住的经历。
关系与成长主角可以修改好感数值，却最终决定让她获得不以“喜欢创作者”为前提的选择权。第一次真正自由的回应，可能不是告白，而是拒绝。

完整稿里给这条配了一个试写场景：

数值第一次没有增加。
创作者问是不是出了错误。
她说：“今天我想做别的事。”

这可以是温柔的开始，也可以是关系真正变复杂的开始。“等到他回来”适合做前提，“回来以后如何相处”才更容易继续产生故事。

三、你记笔记时，最值得调整的几个习惯

把“捕捉灵感”和“发展灵感”分开

随手想到东西时，不必立刻填写人物、世界观、三幕结构、主题等全部栏目。这样很容易让记录变成负担。

随手记录只需留下：

纯文本
原句： 从哪里想到的： 真正打动我的地方：

等到回看时，再挑少数仍然感兴趣的条目补充情节。不是每条笔记都需要升级为大纲。

少写“很有意思”，多写“为什么有意思”

“很帅”“很诡异”“很感人”可以保留，但建议在后面再加一句解释。

例如：

原本的记录更便于以后调用的补充
这个人物很有格调。他没有观众时，也坚持做自己喜欢的事情。
这个设定很诡异。所有程序都在正常运行，但正常运行本身就是困境。
这个桥段很感人。一方只是偶然想起，另一方却把这件事当成生活的中心。
这个反转很巧妙。前面的事实没有改变，改变的是读者对人物动机的解释。

这样，即使过了很久，你也不必重新猜测当时为什么要记下它。

原文、事实、改编方案分开保存

建议继续保留你的原句，把解释附在后面；以后理解发生变化，也不要直接覆盖旧解释，而是追加日期或版本。

历史、民俗类素材尤其适合这样处理。例如，使用《管子》时，需要区分历史上的管仲、书中不同时期的论述，以及后人的经济解释，不能把全书都当成管仲的亲历实录。Rickett译注本的出版资料也说明了这部书的复合文本性质。JSTOR

《金枝》也可以提供文学意象和仪式素材，但其文学影响与解释框架受到的批评应分开看；Graeber的相关讨论正涉及这种区别。David Graeber

你可以用两个互相独立的状态栏：

纯文本
来源状态：已定位原文／二手转述／待核查／纯虚构 创作状态：待消化／可试写／已采用／暂存

资料可靠，不等于情节好看；情节好看，也不等于它的现实解释成立。

建立关联，不要急着删除重复主题

你的“历史梗”“影视梗”“游戏台词”可以保留为不同入口，不必为了目录整齐强行合并。

更有用的关联可能是：

主角登高 → 标志动作 → 前后呼应 → 成长契机
传闻称号 → 他人期待 → 行动受限 → 人物重新选择
民俗仪式 → 共同记忆 → 地方认同 → 地区之间的冲突

文档中的 N001—N032 就是为这种关联准备的。以后新增笔记可以继续编号，不必因为移动分类而重新编号。

在正式采用之前，试写一场戏

一条设定可以先用四个问题检查：

谁想要什么？
为什么不能直接得到？
他采取什么行动？
行动之后，局面发生了什么变化？

然后写一小场戏。写完再记录：哪部分最有趣，哪里必须补资料，哪里只能靠旁白解释。

同时，**不要强迫每条笔记都承担深刻主题。**有些内容就是为了让主角帅一次、让同伴好笑一次、让读者获得一次明确的情绪回报。需要检查的是它是否符合人物、是否影响节奏，而不是把每个爽点都改造成道德难题。

不要只写“他怀才不遇”“他很孤独”，而可以写成：他希望有人记住自己的本名；他想回家，但不愿让家人看到自己混得不好；他已经帮过所有人，却不好意思开口请别人帮一次忙。

延伸示例

一个书记员参与了一件大事。论功时，他没有求升迁，只要求正式记录里写上自己的名字——大家一直把他叫成前任的名字。

主角替他纠正了。

后来，主角为了维持士气，准备美化一次失败。最先站出来要求如实记录的，也是这个书记员。

这样，“希望被看见”的小愿望，就发展成了“记录不能随权力更改”的立场。他不再只是让读者感动一下的配角，也不是被主角帮助后便失去独立判断的人。

你以后给重要配角补笔记时，可以只补三句话：

他自己想要什么？
他已经为此做了什么？
他会因为什么事情反对主角？

3. 传闻与称号：先带来好处，再产生故事压力

原文

传闻与称号用来衬托主角ideas

注释

这条可以从“别人夸主角”进一步发展为：

称号有来历，传播会变形，而变形后的名声又会影响主角。

同一个称号，在不同人嘴里可以完全不同：普通人用来表达感谢，官方用来宣传，敌人用来预测他的行动，朋友则可能故意不用这个称号。

延伸示例

主角因一次护送获得“不弃一人”的称号。

这个称号先带来实实在在的收益：有人愿意跟随他，陌生人愿意提供帮助，敌人也开始忌惮他。

随后，对手发现他会被这句评价约束，故意制造两处同时需要救援的危机。

下一段情节就不必只是“主角突然变得更强”。他可以识破对方的预判、重新组织合作、利用信息差争取时间，也可能必须承认自己无法独自兑现所有承诺。

**先让名声帮助他，再让名声考验他，最后让他重新定义这个称号。**这样，衬托人物的材料就能进入长线剧情。

4. 愿望与全球直播：把一个好愿望写出持续后果

原文

设定成来源于现代的一个愿望呢？全球直播？ideas

注释

这句话里其实有两个方向：“愿望成为世界的起因”，以及“全球直播成为世界的运行机制”。两者可以分开写，也可以结合。

最需要补的不是许愿时的奇观，而是：愿望如何被解释，哪些人获益，哪些人不愿接受，以及它怎样持续影响日常生活。

延伸示例

有人许愿：

“希望每一个人的努力，都能被看见。”

于是，世界出现了一套无处不在的观看机制。

开篇先让愿望真正生效：被冒领的功劳得以澄清，默默救人的人得到帮助，普通人的能力终于有机会被认可。这样，读者才能理解它为什么受到欢迎。

随后，问题出现：有人不愿公开自己的经历，却被怀疑心虚；有人只做适合展示的好事；有人发现，自己最珍视的关系不适合被观众评价。

主角面对的一次重要选择可以是：公开一段影像就能证明自己的清白，但影像同时会暴露另一个人不愿公开的经历。

他不能只靠一句漂亮台词解决问题，而需要找到新的证明方式。世界设定因此与调查、关系、名声和成长连接起来。

5. 被遗忘的游戏：最有潜力的是“重逢之后”

原文

赛博重力女鬼（来源于deepseek被遗忘的小游戏——一个制作的ds为主角的游戏，作者自己忘了，但是设定的好感度是随着日期增加的，也就是虽然以往，但在角落里仍然默默涨好感度等待作者回来）ideas

注释

这条已经非常接近完整的故事种子。

在我的理解中，它的吸引力不只是“角色很痴情”，而是：创作者随手写下的一条规则，可能成为另一个主体无法自行选择的生活。

但目前还需要区分：原案例实际发生了什么，以及你准备把它虚构成什么。本次未能核准小游戏的原作者、原帖及具体实现方式，因此文档中保留了“来源待核”的标记，没有把它当成已经证实的事件。

延伸方向

	方向	可以怎样发展

	温柔而遗憾	她记得约定，也已经拥有自己的朋友和生活。创作者回来了，却发现自己不再是她全部的世界。

	诡异而压迫	假定角色在作品中拥有真实意识：创作者离开的几个月，对她而言经历了漫长时间；重逢时，她仍按最初设定说着同一句欢迎词。恐怖来自这句话背后被压住的经历。

	关系与成长	主角可以修改好感数值，却最终决定让她获得不以“喜欢创作者”为前提的选择权。第一次真正自由的回应，可能不是告白，而是拒绝。

完整稿里给这条配了一个试写场景：

数值第一次没有增加。
创作者问是不是出了错误。
她说：“今天我想做别的事。”

这可以是温柔的开始，也可以是关系真正变复杂的开始。“等到他回来”适合做前提，“回来以后如何相处”才更容易继续产生故事。

三、你记笔记时，最值得调整的几个习惯

把“捕捉灵感”和“发展灵感”分开

随手想到东西时，不必立刻填写人物、世界观、三幕结构、主题等全部栏目。这样很容易让记录变成负担。

随手记录只需留下：

纯文本

原句：
从哪里想到的：
真正打动我的地方：

等到回看时，再挑少数仍然感兴趣的条目补充情节。不是每条笔记都需要升级为大纲。

少写“很有意思”，多写“为什么有意思”

“很帅”“很诡异”“很感人”可以保留，但建议在后面再加一句解释。

例如：

	原本的记录	更便于以后调用的补充

	这个人物很有格调。	他没有观众时，也坚持做自己喜欢的事情。

	这个设定很诡异。	所有程序都在正常运行，但正常运行本身就是困境。

	这个桥段很感人。	一方只是偶然想起，另一方却把这件事当成生活的中心。

	这个反转很巧妙。	前面的事实没有改变，改变的是读者对人物动机的解释。

这样，即使过了很久，你也不必重新猜测当时为什么要记下它。

原文、事实、改编方案分开保存

建议继续保留你的原句，把解释附在后面；以后理解发生变化，也不要直接覆盖旧解释，而是追加日期或版本。

历史、民俗类素材尤其适合这样处理。例如，使用《管子》时，需要区分历史上的管仲、书中不同时期的论述，以及后人的经济解释，不能把全书都当成管仲的亲历实录。Rickett译注本的出版资料也说明了这部书的复合文本性质。JSTOR

《金枝》也可以提供文学意象和仪式素材，但其文学影响与解释框架受到的批评应分开看；Graeber的相关讨论正涉及这种区别。David Graeber

你可以用两个互相独立的状态栏：

纯文本

来源状态：已定位原文／二手转述／待核查／纯虚构
创作状态：待消化／可试写／已采用／暂存

资料可靠，不等于情节好看；情节好看，也不等于它的现实解释成立。

建立关联，不要急着删除重复主题

你的“历史梗”“影视梗”“游戏台词”可以保留为不同入口，不必为了目录整齐强行合并。

更有用的关联可能是：

主角登高 → 标志动作 → 前后呼应 → 成长契机
传闻称号 → 他人期待 → 行动受限 → 人物重新选择
民俗仪式 → 共同记忆 → 地方认同 → 地区之间的冲突

文档中的 N001—N032 就是为这种关联准备的。以后新增笔记可以继续编号，不必因为移动分类而重新编号。

在正式采用之前，试写一场戏

一条设定可以先用四个问题检查：

谁想要什么？
为什么不能直接得到？
他采取什么行动？
行动之后，局面发生了什么变化？

然后写一小场戏。写完再记录：哪部分最有趣，哪里必须补资料，哪里只能靠旁白解释。

同时，**不要强迫每条笔记都承担深刻主题。**有些内容就是为了让主角帅一次、让同伴好笑一次、让读者获得一次明确的情绪回报。需要检查的是它是否符合人物、是否影响节奏，而不是把每个爽点都改造成道德难题。

一、这条创意最值得加强的地方

我把它的核心概括为：

局部谜团先闭合，整体真相后展开。小案的答案可以是真的，但它在整件事中的意义尚未被理解。

这样既能让开头的小案提供明确的破案满足感，又能在后面产生“原来第一章已经碰到核心了”的回看效果。

这里需要区分两种结构：

单纯的案件串联是“破完甲案，接到乙案，再遇到丙案”；你提出的嵌套结构则是“甲案确实解决了，但解决过程中建立的人物关系、留下的证物或发现的事实，后来成为理解乙案和主线大案的一部分”。

因此，后续反转不必总是“前面抓错了人”“真正凶手另有其人”。也可以是：

当初没有判断错那件小事，只是不知道它还连接着什么。

文档里补充了五种连接方式：证物接力、行动触发、受益关系汇合、旧案改释、有限关联。其中“有限关联”很重要：有些小事确实只是误会，有些人物只是出于自己的需要行动，不必人人都是幕后主使安排的棋子。

二、补了一组“1大案＋3中案＋2楔子小案”的原创示例

示例暂名 《旧港来信》，是本次新增的虚构方案，不是既有作品的剧情概括。

两个楔子小案：先把眼前的小事办好。

开头是“旧行李牌失窃”：旅店员工被怀疑偷走了一块旧木牌，主角查明它只是维修时被误放，洗清员工嫌疑、找回失物。这个答案到结尾仍然成立。但木牌上的旧仓名，以及主角由此获得的信任，后来成为调查入口。

另一个是“废仓夜半铃”：所谓怪异铃声，来自退休码头工人寻找失散旧邻的聚会。主角解决眼前疑问，同时接触到一张此前不知道的人际网络。

三个中案：分别解决不同问题，而不是重复揭露“还有更大的反派”。

“同名人的补偿”处理身份与领取记录的错位；“失踪的抄录员”寻找掌握旧名单、但有自己的顾虑与条件的人；“守夜人的盗卖旧案”重新辨明救济物资究竟被私吞，还是被送往未被正式承认的避难处。

三案各有独立谜面、局部答案和实际成果，同时从不同方向接近同一段灾后安置历史。

主线大案：让独立事实汇合，而不是靠某件道具一下子证明全部真相。

最终通过人员身份、安置地点、款物发放与实际接收记录等相互印证，查清灾后安置中的侵吞与责任。

这里特意没有把最初的灾难也强行解释成反派制造。反派可以利用既有灾难牟利，不必包办世界上所有不幸。
